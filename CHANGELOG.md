## Changelog policy

Update this file in the same pull request as user-visible changes. Add entries under `Unreleased` in the Added, Changed, Deprecated, Removed, Fixed, or Security category. At release preparation, move the relevant entries into a version-and-date heading, leave a fresh `Unreleased` section, and link the release tag when one exists. Do not record plans as completed work.
