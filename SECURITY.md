# Security policy

ATOM Studio is under active development. The desktop shell is not a production release, and planned security controls are not yet implemented in the application.

## Reporting a vulnerability

Please do not disclose vulnerabilities, exploit steps, credentials, or sensitive user data in public issues or pull requests. Use the repository's **Security → Report a vulnerability** private reporting channel:

https://github.com/ABHINAY-TOMAR/ATOM-studio/security/advisories/new

If private vulnerability reporting is unavailable, contact the repository owner using a private contact method listed on their GitHub profile. Do not post sensitive details publicly while seeking a reporting channel.

## Scope and response

Reports should include affected commit/version, impact, reproducible steps, and any safe proof of concept. The maintainer will acknowledge and triage reports as availability allows. No response-time SLA or supported release policy is currently established.

Do not test against systems or accounts you do not own or have explicit permission to assess.
